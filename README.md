# Resource Loop 🔄♻️

A campus-focused web platform designed to help students buy, sell, and trade academic resources and essentials effortlessly within their college community.

🔗 **Live Demo:** [Check it out on Render](https://resource-loop-9j1g.onrender.com/)

## ✨ Key Features

- **Campus-Focused Marketplace:** Connects seniors/students who want to sell resources with students looking for quality, affordable items.
- **Featured Student Essentials:** Browse commonly requested items like lab coats, scientific calculators, first-year physics notes, and engineering drawing (ED) kits.
- **Smart Features:**
  - User-friendly interface
  - Verified student login system
  - Smart listing system
  - Built-in chat for negotiation
  - Sustainability impact dashboard

## 🛠️ Built With

- **HTML5** – Structured semantic layout.
- **CSS3** – Custom styling and responsive design.
- **JavaScript** – Interactive UI elements.
